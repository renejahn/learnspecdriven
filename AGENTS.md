# Agent guidance

This is a static educational site: vanilla HTML, CSS and JavaScript; no frameworks or third-party runtime dependencies.

- Preserve accessible semantic markup and keyboard interactions.
- Keep lessons grounded in the cited primary sources; distinguish recommendations from guarantees.
- Never suggest executing unreviewed agent-generated commands, revealing secrets, or skipping tests.
- Keep examples vendor-neutral where possible.
- Test with `python3 -m py_compile serve.py`, `node --check app.js` if Node is installed, and start `./serve.sh` to check pages load.
- Review specification, tasks, implementation and verification evidence before declaring completion.
